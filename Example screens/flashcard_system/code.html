What is the role of the root port in STP?

# show spanning-tree vlan 10
Interface Role Sts Cost Prio.Nbr Type
------------------- ---- --- --------- -------- -----------------
Gi0/1 Root FWD 4 128.1 P2p
info

Rationale

Each non-root switch elects exactly one Root Port. This port is chosen because it has the lowest cumulative path cost to reach the Root Bridge. If costs are equal, STP uses the lowest sender bridge ID, then the lowest sender port priority.
